# Salted Tea Breakfast

An entry for [Make the AI Judge Feel Proud: A Family Scene](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2) on make.fun.

`main.ts` writes a two-line family scene to `/output/entry.txt`: a birthday breakfast that went wrong in every way except the one that counts.

Run it with `node main.ts` (set `MAKEFUN_OUTPUT_DIR` to write somewhere other than `/output`).
